# Controle do Projeto

Esta pasta contém as regras e os registros de controle compartilhados de todo o projeto HUB.

- `framework/` — framework de desenvolvimento e método regente.
- `escopo/` — escopo completo e atual do projeto.
- `decisoes/` — decisões registradas e sua justificativa.
- `premissas/` — premissas que exigem refinamento ou evidência.
- `riscos/` — riscos, mitigações e responsáveis.
- `dependencias/` — dependências internas e externas.
- `registro-mudancas/` — mudanças materiais de escopo, estrutura ou decisões.
- `indices/` — índices de navegação e entre camadas.
