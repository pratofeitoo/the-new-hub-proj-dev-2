# MVP — Acadêmico & Educação

Esta pasta reúne o material de aplicação do MVP Firjan como referência para a frente Acadêmico, conectando universidade, estudantes, pesquisa e empresas.

## Tese

Conhecimento acadêmico pode gerar valor para empresas, enquanto desafios empresariais podem gerar oportunidades de formação, pesquisa aplicada, bolsas, estágios e carreira.

## Aplicação inicial

O modelo de candidatos serve como base operacional para testar perfis, oportunidades, matching, projetos e indicadores. O contexto acadêmico deve ser delimitado por uma instituição, um conjunto de oportunidades e critérios claros de resultado.

## Escopo recomendado

- portal da universidade;
- perfil acadêmico do aluno;
- oportunidades acadêmicas;
- projetos empresa–universidade;
- matching aluno–projeto;
- estágios e carreira;
- bolsas corporativas;
- indicadores universidade–mercado.

Perfil avançado de pesquisadores, matching pesquisador–empresa, trilhas e acompanhamento completo de projetos podem ser evoluções posteriores.
