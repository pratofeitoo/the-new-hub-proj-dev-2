# MVP — Candidatos & Oportunidades

Esta pasta reúne o MVP Firjan, voltado à jornada **formação → oportunidade → contratação**.

## Objetivo

Conectar pessoas formadas pela Firjan às vagas e demandas de empresas associadas, acompanhando o processo até entrevista e contratação.

## Dimensionamento

- 10 empresas;
- até 1.000 candidatos;
- 2 recrutadores por empresa;
- aproximadamente 50 oportunidades;
- cerca de 500 matches apresentados;
- 30 contratações como hipótese de capacidade, não promessa.

## Fluxo

Importar candidatos → mapear competências → cadastrar oportunidades → fazer match → apresentar shortlist → acompanhar seleção → registrar contratação → medir impacto.

## Escopo do MVP

Importação administrativa, perfil, oportunidades, matching por regras ponderadas, shortlist, candidatura, funil seletivo, feedback, dashboard Firjan e dashboard empresarial. Recomendações de desenvolvimento e relatório completo ficam para a Fase 2.

## Indicadores

O case deve acompanhar aderência das oportunidades, tempo até a primeira oportunidade, match/entrevista, entrevista/contratação, conversão final, lacunas de competências e motivos de não avanço.

## Arquivo principal

`fontes/HUB_MVP_Firjan_10_Empresas_1000_Candidatos.xlsx` contém escopo, capacidade, custos, caixa e plano de validação. As taxas e volumes são editáveis.

Este README é o documento-resultado inicial do cartão [[05-resources/inbox/Plataforma HUB/00-entrada/piloto-firjan-processamento.md|piloto-firjan-processamento]]. O workbook original permanece preservado em `fontes/` e não foi movido.

### Fatos observados

- O modelo estrutura a jornada formação → oportunidade → contratação para 10 empresas e até 1.000 candidatos.
- O escopo inclui perfis, oportunidades, matching, shortlist, funil, feedback e indicadores.

### Hipóteses

- Os volumes e as taxas do workbook são premissas editáveis; as 30 contratações são capacidade estimada, não promessa.

### Decisões

- O resultado deste piloto foi classificado para `02-refinement` após revisão do cartão de processamento.

### Lacunas abertas

- Ainda faltam autorização da Firjan, dados anonimizados, critérios de matching, baseline e critérios de aceite para validar as taxas reais.
