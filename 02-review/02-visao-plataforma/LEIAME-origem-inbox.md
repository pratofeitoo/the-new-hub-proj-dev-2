# HUB · Visão da Plataforma

> Artefatos da visão de longo prazo da HUB: organização, portfólio, finanças, arquitetura, custos e materiais de apresentação.

Esta pasta reúne os materiais que descrevem como a HUB pode evoluir de casos e MVPs delimitados para uma plataforma conectada. Ela funciona como referência estratégica e de planejamento; não substitui a validação dos MVPs em [`01-mvps/`](../01-mvps/).

## Organização interna

Os diretórios de conteúdo seguem, quando aplicável, a mesma convenção:

- `fontes/` — documentos e arquivos originais;
- `notas/` — versões em Markdown e sínteses de trabalho;
- `dados/` — dados auxiliares, tabelas e artefatos estruturados;
- `visuais/` — imagens, referências e materiais visuais.

Algumas pastas também contêm subdiretórios específicos para versões ou análises detalhadas, como `Arquitetura-Custos/` e `Arquitetura-Custos_FullFidelity/`.

## Como usar

1. Começar pelo README do diretório específico de interesse.
2. Consultar `fontes/` para verificar o material de origem.
3. Usar `notas/` para leitura rápida e sínteses editáveis.
4. Conferir `dados/` e os modelos antes de reutilizar números ou premissas.
5. Tratar projeções, custos e hipóteses como material de planejamento, não como compromisso comercial, orçamento contratado ou obrigação jurídica.

## Relação com os MVPs

```text
Visão completa → hipótese vertical → MVP limitado → case mensurável
→ processo replicável → módulo de produto → plataforma conectada
```

As decisões de construção devem partir de evidências dos MVPs. A existência de uma arquitetura, produto ou projeção nesta pasta não significa que sua implementação tenha sido aprovada.

## Critérios de manutenção

- preservar os arquivos originais em `fontes/`;
- registrar versões em `notas/` sem substituir silenciosamente a fonte;
- indicar quando números são hipóteses ou projeções;
- manter os READMEs internos sincronizados com os caminhos reais;
- atualizar este índice quando novos blocos de visão forem adicionados.
