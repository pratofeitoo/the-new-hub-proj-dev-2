# Visual Philosophy — Chromatic Cartography

These sitemaps treat product structure as a field of navigation rather than a spreadsheet. Meaning is carried first by spatial position, repeated geometry, and color-coded lanes; text is deliberately compact, acting as a label inside the map instead of becoming a second document around it.

The composition uses a quiet neutral ground and a disciplined six-lane grid. A single pink root establishes the shared origin, while the colored columns create a stable visual grammar that survives comparison between specimens. Yellow gates interrupt the flow only where a human or system decision actually occurs; dashed nodes expose absence without disguising it as a completed capability.

Rhythm comes from repeated cards, measured gaps, and restrained connectors. Every lane has the same visual weight even when its evidence is deeper, so the viewer can compare breadth without confusing density for maturity. The map should feel meticulously crafted: consistent baselines, readable labels, generous breathing room, and no decorative element that competes with the decision.

The refinement is intentionally analytical but not cold. Soft surfaces, crisp borders, subtle elevation, and accessible contrast make the artifact legible on screen and in print. The result should look like a master-level systems map produced through painstaking attention: a visual instrument for finding overlap, exposing gaps, and deciding what deserves the next build.
