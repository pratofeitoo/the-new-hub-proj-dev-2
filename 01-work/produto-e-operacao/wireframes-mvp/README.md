# Wireframes MVP HUB

Esta pasta contém a primeira composição visual navegável das telas MVP. O arquivo [index.html](./index.html) usa dados sintéticos, não representa uma implementação funcional e não substitui a validação do [plano de mapeamento](plano-mapeamento-telas-plataforma-hub.md).

## Telas incluídas

- Cockpit executivo (`SCR-01` / `WF-01`)
- Painel do gestor (`SCR-02` / `WF-02`)
- Minha jornada (`SCR-03` / `WF-06`)
- Governança de KPIs (`SCR-04` / `WF-04`)
- Alertas e decisões (`SCR-05` / `WF-03`)
- ROI do HUB (`SCR-06` / `WF-05`)
- Diagnóstico de dados (`SCR-07` / `WF-07`)

## Direção visual

Shell claro, tipografia compacta, azul índigo para estrutura, teal para estados positivos, âmbar para pendências e vermelho somente para risco crítico. Todos os valores estão identificados como sintéticos.

## Limites

O protótipo é uma composição visual e de navegação local. Ele não executa RBAC/ABAC, não conecta fontes, não calcula ROI real e não autoriza uso de dados reais.
