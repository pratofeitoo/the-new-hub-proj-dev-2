# Saídas do sistema de apresentações HUB

Este diretório agrupa as saídas por finalidade. Os artefatos permanecem em `01-work/` e continuam sendo materiais provisórios; a organização não constitui promoção para revisão ou aprovação.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `arquitetura-de-marca/` | HTML e PDF da apresentação de arquitetura de marca. |
| `plataforma-estrategica/` | HTML e PDF do piloto da plataforma estratégica. |
| `brand-kit/` | Pranchas PNG e documentação Markdown do brand kit provisório. |

O `.DS_Store` permanece na raiz como metadado local do macOS e não faz parte do inventário editorial.

## Regra de manutenção

Ao adicionar uma nova saída, coloque-a na subpasta correspondente e atualize os manifests, registros ou planos que apontem para o caminho. Use `git mv` para reorganizações de arquivos versionados, preservando o histórico.
